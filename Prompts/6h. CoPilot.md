  - This should be done via an IconSpacing property
- I want to add a DirectionFlow property, so that if Placement = ddpLeft or Placement = ddpRight I can set DirectionFlow := difTopToBottom or difBottomToTop or if Placement = ddpBottom or Placement = ddpTop then I can set DirectionFlow := difLeftToRight or difRightToLeft
  - This change is to extend the functionality and to allow the items to flow Right to Left and Bottom to Top as well as Top to Bottom and Left to right which they currently do
- Placement = ddpLeft or Placement = ddpRight ONLY: I need to add a Collapse / Expand option so that a Dock can be collapsed ( Use < icon ) or expanded ( Use > icon )
  - There should be a ShowExpandCollapse property, so that the < > icons may be hidden and a user cannot click then
  - For Placement = ddpLeft, DirectionFlow := difTopToBottom the < > icons should be in the bottom right corner and should be no bigger than 16 x 16
  - For Placement = ddpRight, DirectionFlow := difTopToBottom the < > icons should be in the bottom left corner and should be no bigger than 16 x 16
  - For Placement = ddpLeft, DirectionFlow := difBottomToTop the < > icons should be in the top right corner and should be no bigger than 16 x 16
  - For Placement = ddpRight, DirectionFlow := difBottomToTop the < > icons should be in the top left corner and should be no bigger than 16 x 16
  - Fully expanded the Dock should go back to the width defined by SizeKind
  - Fully collapsed the Dock should go back to a width of 16 and the only icons visible should be collapse and expand
  - There should never be any text under the < or > icons
